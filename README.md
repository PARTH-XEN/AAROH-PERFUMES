## 🌹 About the Project

**AAROH PERFUMES** is a luxury fragrance website designed to bring the world of premium perfumery into an immersive digital experience.

Built with modern frontend technologies, the project focuses on combining sophisticated visual storytelling, elegant presentation, and smooth motion to create a memorable fragrance-brand experience.

From cinematic visuals to refined interface elements, every part of AAROH aims to communicate the beauty and identity of luxury fragrances.

> A fragrance is more than a scent. It is an identity, a memory, and an expression of elegance.

## 🚀 Getting Started

Want to run AAROH PERFUMES locally? Follow these steps.

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/PARTH-XEN/AAROH-PERFUMES.git
```

### 2. Enter the Project Directory

```bash
cd AAROH-PERFUMES
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

## 📦 Deployment

The repository includes a `vercel.json` configuration, making Vercel a natural deployment option.

General deployment steps:

1. Push the project to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Configure the project using the Vite build settings.
4. Deploy the application.

Typical build settings:

```text
Framework: Vite
Build Command: npm run build
Output Directory: dist
```
